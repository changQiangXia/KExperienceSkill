# 赛前 40 项故障预检

> 每条都是"会在上分路上扣分或直接判负"的坑。开赛/提交前逐条打勾；命中即处理。

## A. 数据与标签（8）

- [ ] 实体键审计：是否整体落在 train 或 test？会否跨折泄漏？
- [ ] 重复/近重复：精确 hash + 近邻（图/文本）是否已检查？
- [ ] 哨兵值：-1/-666/999/空串/none vs None 是否已扫描？
- [ ] test OOD 类别：train 无 test 有的取值如何编码？
- [ ] 缺失结构：缺失是否与目标相关？是否加缺失指示？
- [ ] 时间泄漏：滚动特征是否"截至当前"？标签窗口是否穿越？
- [ ] 标签口径：多标注/单标签/presence-only 是否与评测一致？
- [ ] 合成痕迹：生成顺序/索引/孪生行/重复倍数是否利用？

## B. 验证与指标（7）

- [ ] 官方 metric 实现已下载、可运行、有单元测试？
- [ ] fold 列已保存，所有实验共用？
- [ ] 随机/分组/时间切分与数据生成方式一致？
- [ ] 已记录 ≥3 次提交的（CV, LB）用于相关性判断？
- [ ] 公榜样本量/占比已知？是否小到只能当随机变量？
- [ ] 合成赛已做随机目标 z 检验？
- [ ] 原数据/外部数据已做对抗验证与 CV 增益对照？

## C. 指标与后处理（6）

- [ ] 指标数学结构已归类（中位数/排序/阈值/容差/概率/方差/对局）？
- [ ] 3–5 个后处理候选已在 OOF 上对照？
- [ ] 校准是单参数还是灵活方法？小数据是否过量？
- [ ] 裁剪/档位/阈值的参数来自 OOF 而非 public LB？
- [ ] 预测值形态符合评测要求（范围/整数/概率和）？
- [ ] 重复行/极端值是否会让指标只由少数样本决定？

## D. 模型与集成（6）

- [ ] 至少一个与现有模型跨家族、OOF 相关性 <0.99 的模型？
- [ ] 集成权重在 OOF 上拟合，无折内泄漏？
- [ ] Optuna 参数过了换种子稳定性检验？
- [ ] 低信号场次是否设了"够了就停"的预算？
- [ ] 伪标签/蒸馏有同折对照，且没有污染验证？
- [ ] 多目标是否做过"拆 vs 合"实验？

## E. 提交与平台（7）

- [ ] sample_submission 列顺序/行数/ID 集合完全一致？
- [ ] 代码赛的 zip/图片/kernel 结构演练通过？
- [ ] 提交提前 48h 完成，状态为 Submitted，截图留证？
- [ ] 额度/配额/预算/TPU 排队时间已评估？
- [ ] API key/凭证不在提交物中，日志不打印 token？
- [ ] 公开 notebook/数据集满足比赛共享规则？
- [ ] 最终候选与未选候选、选择理由已记录？

## F. Agent/LLM（4）

- [ ] 模型-工具兼容性表已读（单工具/无工具/温度限制）？
- [ ] agent schema 已用官方校验器本地通过？
- [ ] 预算与 session 时长上限写进 agent 计划？
- [ ] LLM 给出的引用/来源已逐条核验？

## G. RL / 自对弈（2）

- [ ] 规则基线先于 RL 建立，并有可解释评分函数？
- [ ] 训练收益拐点（KL/资源/胜率）有早停标准，且对手池含多样性？

## 症状 → 修复速查

| 症状 | 首选修复 |
| --- | --- |
| CV 好、LB 崩 | 实体/时间泄漏；提交格式；降公榜依赖 |
| 提交 0 分/报错 | submission_guard + 最小提交演练 |
| 分数扎堆动不了 | 指标结构后处理（不是继续调参） |
| 前排差距 1e-4 | 稳定性/集成/后处理，而非大改模型 |
| 公榜高私榜崩史 | 提交组合对冲 + 保守候选 |
| schema/工具报错 | 先跑官方失败清单与本地校验 |
