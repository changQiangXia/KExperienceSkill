# 深案例库（Case Deep Dives）

> 从 264 场中挑出最有教学价值的 ~40 场，按"场景 / 机制 / 关键数字 / 可迁移配方 / 失效条件 / 证据"展开。
> 用途：为新比赛生成改进方案时，先在这里找结构同构的案例，把"机制"翻译成本场实验，而不是照抄参数。

## 一、表格与合成数据

### playground-series-s3e25 — MedAE 的结构套利
- **场景**：莫氏硬度回归，中位绝对误差（MedAE），1632 队。
- **机制/发现**：MedAE 只取决于误差中位数那一个样本；极端易/难样本几乎不影响分数。把预测向目标分布的分位/档位整形是主要得分手段。
- **关键数字**：AE≤0.06 或 ≥0.7 的样本权重 0.01 → CV +0.03；9 档 ±0.25 覆盖 89.5%（9533/10406）；猜对约 56% 即 MedAE=0.25；200+ 提交卡在 0.25；LAD Stacker LB 0.49737。
- **可迁移配方**：① 判断指标是否"中位数型"；② OOF 上扫描样本权重阈值；③ 预测向训练分布档位/分位整形；④ 用 OOF 而非 LB 定阈值。
- **失效条件**：测试分布与训练不同构；档位阈值经验化。
- **证据**：455888 / 457631 / 455289。

### playground-series-s5e9 — 随机目标检验与窄分带
- **场景**：歌曲 BPM 回归（RMSE），2581 队；原数据近似随机。
- **机制/发现**：用 100 次打乱目标训练同款 XGB 做 z 检验；判随机后，收益转向生成痕迹、稳健集成与分布决策。
- **关键数字**：原目标 CV z=-0.83；近 6 场回归 3/6 随机（S4E12/S5E2/S5E9）；榜首分带 26.38–26.41；未选用提交 private 26.40277 反而更高。
- **可迁移配方**：① 开赛 10 分钟做 z 检验；② 无信号时压缩模型预算；③ 分数带≈噪声时用 CV/形态决策；④ 伪标签必须有同折对照。
- **失效条件**：原数据可得性；z 检验只判原数据信号，不判合成结构。
- **证据**：604028 / 609999 / 610264 / 610016。

### playground-series-s3e18 — 多目标"两场比赛"
- **场景**：分子 EC1/EC2 多标签（AUC 平均），1047 队。
- **机制/发现**：两个目标的最优模型族完全反转——EC1 树模型、EC2 Bagged KNN；EC2 天花板 ~0.58–0.59。
- **关键数字**：EC1：KNN 0.6981 < LR 0.7005 < ET 0.7073 < RF 0.7087 < Ensemble 0.7092；EC2：LR 0.5773 < KNN 0.5859 < RF 0.5865 < ET 0.5883 < Ensemble 0.5888；EC1 重要特征 ~19、EC2 ~7；11th 私榜 0.66095。
- **可迁移配方**：① 每目标单独小调参，比较最优模型族；② 拆/合都做对照；③ 特征选择按目标分开；④ 低天花板目标设"够了就停"。
- **失效条件**：重 FE 的多输出也可能赢（1st），不能教条拆分。
- **证据**：420127 / 420822 / 421210 / 423642 / 432011。

### playground-series-s3e8 — 分组合法性裁剪
- **场景**：宝石价格回归（RMSE），734 队。
- **机制/发现**："清洗训练离群值"会让 CV 好、LB 崩（模型本来在压缩极值）；正确做法是用训练组的分位上下界约束测试预测。
- **关键数字**：按 carat 滑窗 0.15 × cut × clarity × color（>5 条）分组；上界 Q3+1.5·IQR（+0.2 LB）；下界抬到组内训练最小值（再 +1.1 LB，进前 10）；2nd 用 1816 模型两级栈（L1 cutoff 572.6）。
- **可迁移配方**：① 先判断模型是否已在压缩极值；② 按业务分组构造合法区间；③ 对预测裁剪而非重训；④ 分组样本量门槛。
- **失效条件**：分组样本不足；目标本身可超出历史范围。
- **证据**：392860 / 392828 / 392824。

### playground-series-s3e22 — 实体复用与 7 区域洗牌
- **场景**：马匹疝痛 3 分类（F1），1541 队；小数据 + 20/80 划分。
- **机制/发现**：public/private 名次大面积翻转；同一 hospital_number 的马会"死多次"；LB 选择本身是噪声。
- **关键数字**：7 区域散点（region 2/6 公榜好私榜崩，3/4/5 CV 可信者反弹）；14th 选中版本 0.76818、未选版本 0.77121；top 11 中 7 队只提交 1–2 次；micro-F1 = accuracy。
- **可迁移配方**：① 实体键审计 + 分组 CV；② 提交组合对冲；③ 以 CV 选提交；④ 小数据集不要用 LB 选模。
- **失效条件**：实体键可能是合成伪影，需先验证语义。
- **证据**：444654 / 444642 / 441284 / 440333。

### playground-series-s3e9 — CV 是测量，LB 是随机变量
- **场景**：混凝土强度回归（RMSE），765 队。
- **机制/发现**：CV 5407 样本 vs 公榜 721 样本；样本量差使 LB 分数成为高方差随机变量。
- **关键数字**：1st GB+RF+Ridge ≈12.03 vs 单 Ridge ≈12.16；主张 ≤2 次提交；Optuna 参数换 KFold 种子后不存活；重复行目标分箱使线性模型 ~14→12。
- **可迁移配方**：① 先算 CV/LB 样本量比；② 锁死 CV 口径；③ 调参做种子稳定性检验；④ 跨家族多样性集成。
- **失效条件**：CV 与测试不同分布时，样本量论点不成立。
- **证据**：394592 / 394600 / 394641。

### playground-series-s3e14 — 目标唯一值吸附
- **场景**：蓝莓产量回归（MAE），1875 队；目标只有 776 个唯一值。
- **机制/发现**：把预测吸附到最近的唯一目标值即 +0.3 MAE；原始数据中存在确定性映射（fruitset/fruitmass → yield），可定点覆盖。
- **关键数字**：776 唯一值；吸附 +0.3；1st 用共同取值覆盖测试 2073 条并分级风险提交；13th 用 OOB 当 OOF、只提交 4 次。
- **可迁移配方**：① 统计目标唯一值/离散度；② OOF 上对比吸附/不吸附；③ 找原始数据的确定性映射（合规前提下）；④ 风险分级提交。
- **失效条件**：测试目标连续或口径不同；映射使用需规则允许。
- **证据**：407327 / 410627 / 410639 / 410652。

### playground-series-s5e2 — 孪生行与生成结构
- **场景**：背包价格回归（MSE），3393 队；原数据 10% 重复、每条合成行约 80 份副本。
- **机制/发现**：信号不在特征-价格关系，而在同源行；`groupby(COL1)[COL2].agg` 是核心 FE。
- **关键数字**：5e4 行原数据扩到 4e6（≈80×）；KNN k=1 可找孪生行；1st 单模型 XGB + 500 特征夺冠（138 特征版同第一）；AutoGluon 25 模型 CV 38.593/LB 38.853（gap 0.26）vs Ridge CV 38.639/LB 38.839（gap 0.2）。
- **可迁移配方**：① 检验重复倍数与同源结构；② groupby 统计全组合 + 直方图分桶；③ 用 gap 大小识别过拟合候选。
- **失效条件**：生成器未留同源结构；重复结构被官方移除。
- **证据**：565539 / 564056 / 565583。

## 二、金融、信用与在线时序

### amex-default-prediction — 头部排序 + 噪声注入 + 短序列
- **场景**：信用卡违约（自定义 Gini + top-x% capture），4874 队。
- **机制/发现**：指标只看头部排序；数据被注入 (0,0.01] 均匀噪声；短序列客户行为迥异。
- **关键数字**：二次去噪 LGBM +0.0007 / XGB +0.0008 / CatBoost +0.0004；折数 5k→15k +0.0013；CatBoost 延长早停 +0.002；短序列违约率 seq=13→23.2%、12→38.9%、11→44.7%；冠军组件权重和=0.9 也夺冠。
- **可迁移配方**：① 先确认指标是头部排序；② 分序列长度建模弱子群；③ 行级噪声结构（指示列）修复；④ 头部指标下不要迷信 LB 微差。
- **失效条件**：噪声结构不相关；短序列子群占比过小。
- **证据**：THEORY 记录（amex 深读）/ 13th/10th/1st。

### jane-street-real-time-market-data-forecasting — 在线学习 + 时延工程
- **场景**：评测期每日/每周实时训练推理（~1 分钟/日），零均值 R²，3757 队。
- **机制/发现**：非平稳 + 在线约束；验证窗口对齐与推理时延决定分数，模型结构次要。
- **关键数字**：8th 用 2 折时序 CV（每折 200 天）+ 200 天 gap，GRU 双架构 ×3 seed → 0.0112；公榜 17th 每天对最近 7 天训 7 epoch 是主要提分来源，赛后改"每 8 天对最近 56 天重训"更好；162nd 用 70% 在线 TabM MLP（每天微调 10 epoch、lr 1e-5）+ 30% 静态 LGBM；简单 MLP 0.0064。
- **可迁移配方**：① 复制评测窗口做 CV；② 在线学习（小 lr + 混旧数据）；③ 时延预算优先；④ 简单模型 + 训练细节常胜复杂结构。
- **失效条件**：评测不支持在线训练；数据非平稳性弱。
- **证据**：8th 帖 / 公榜 17th / 162nd / 550849。

### hull-tactical-market-prediction — Sharpe 让位于组合构建
- **场景**：单指数仓位（0–2），Sharpe，3677 队。
- **机制/发现**：第 4 名完全不用 ML：已验证的短期反转 alpha + 逆波动率加权 + 波动率目标；大量堆模型的选手被噪声打败。
- **关键数字**：4th 公式 Portfolio = Alpha + Risk Management；2.6 公榜方案把 6800 特征筛到 ~130，重定义目标（正收益 top10%→4、负收益 bottom10%→-2、0/2 分界用无风险利率 ≈3.25%）；61st 用 14 特征 + 224 时序特征单 LGBM，集成"一致更差"。
- **可迁移配方**：① 把指标翻译成经济行为；② 组合层/风险层先行；③ 目标工程（阈值/相对化）；④ 在不确定问题上优先简单稳健。
- **失效条件**：预测精度本身可达时另说；风险模型假设变化。
- **证据**：673 帖系列 / 718664 / 663043 / 715547。

### optiver-trading-at-the-closing — 结构性后处理 + 在线重训预算
- **场景**：收盘竞价价格变动（MCMAE），4436 队；target 跨股票加权和恒为 0。
- **机制/发现**：零和约束让"减加权均值/零和投影"成为近乎免费的后处理；在线重训有明确递减收益。
- **关键数字**：1st 在线消融：不更新 5.4438 → 1 次 5.4157 → 5 次 5.4030；后处理三模型 5.8142→5.8117（≈0.005）；9th 只用 157 特征、最近 45 天权重 1.5、只重训 2 次。
- **可迁移配方**：① 找指标的结构约束（求和/排序/单位）；② 后处理先在 OOF 验证；③ 在线重训算边际收益，不盲目高频。
- **失效条件**：约束在隐藏测试中被破坏。
- **证据**：1st/9th 帖与消融表。

### home-credit-credit-risk-model-stability — 可操纵复合指标
- **场景**：违约概率 + Gini Stability，3856 队。
- **机制/发现**：指标可被提交策略影响；1st 把比赛切成两段做风险下注；中性下注 + 双提交对冲优于单边。
- **关键数字**：模型池私榜上限 ≈0.53；集成 CV 0.712/公 0.605；后处理 WEEK_NUM 1/2 + REDUCE −0.03：公开 0.605→0.654、私有 0.605；模型差距 0.00X vs 参数差距 0.0X。
- **可迁移配方**：① 分析指标能否被策略操纵；② 参数敏感性评估；③ 双提交对冲；④ 别把全部预算压在单边。
- **失效条件**：官方修补指标/禁止相关策略。
- **证据**：1st 表与图。

## 三、CV：细粒度与多模态

### sorghum-id-fgvc-9 — 域适应组合拳
- **场景**：高粱品种细粒度分类，252 队；train/test 来自两块田。
- **机制/发现**：分辨率与域适应是最大杠杆，伪标签/外部数据其次。
- **关键数字**：3rd 消融：直方图均衡 +0.03、IBN-ResNet +0.05、ArcFace(m=0.3) +0.015、512→1024 +0.04、FGVC8 +0.03、TTA +0.02（≈0.957）；2nd 512→960 私榜 84.1→91.9，伪标签 +3.2、dropout +0.2、集成 95.9；1st 223 类 +5 折私榜 0.965。
- **可迁移配方**：① 分辨率上限实验；② IN/直方图/颜色归一化；③ 度量损失；④ 外部数据映射 + 伪标签；⑤ TTA/多折集成。
- **失效条件**：域差不可见/数据量不足时，重手段可能过拟合。
- **证据**：328593 / 329414 / 329049。

### hotel-id-to-combat-human-trafficking-2022 — 遮挡增强与检索/分类之争
- **场景**：酒店图像检索（MAP@K），82 队；测试图有大型遮挡。
- **机制/发现**：训练无掩码、测试有掩码的域差是核心；BlendFlip 增强与统计掩码生成分别解决。
- **关键数字**：1st BlendFlip +0.03–0.04 mAP；5 模型 1536D → PCA 3072D（99% 方差）→ kNN；2nd md5 去重后 45,769 类、3116 类微调 +0.03、集成私榜 0.717；3rd logits 优于 kNN，最佳单模 0.672。
- **可迁移配方**：① 量化 train/test 掩码分布差；② 按测试分布做增强；③ 检索 vs logits 都建本地验证；④ 去重 + 方向校正。
- **失效条件**：掩码分布未知或测试掩码随机。
- **证据**：328281 / 328345 / 328237。

### herbarium-2022-fgvc9 — 细粒度增益分解
- **场景**：83.9 万张标本图 Macro F1，134 队。
- **机制/发现**：损失（多级 CE + subcenter-ArcFace）、分辨率、冻结策略是主增益；重采样与清洗无效。
- **关键数字**：单模 0.78442→0.86282（多级 CE +0.011、LR 5e-4 +0.01、5crop +0.005、subcenter-ArcFace +0.017、额外 CE 头 +0.007、增强 +0.006、384 +0.017、冻结解冻 +0.008、SwinV2 +0.003）；8 骨干融合 0.87662。
- **可迁移配方**：① 长尾用度量损失 + 层级监督而非重采样；② 分辨率/多尺度；③ 渐进解冻；④ 按公榜/OOF 权重融合需防过拟合。
- **失效条件**：类别数小或数据充足时，度量损失增益下降。
- **证据**：329299 / 323906。

### planttraits2024 — 身份辅助任务 + 分层学习率
- **场景**：植物 6 性状均值回归（R²），398 队；多模态。
- **机制/发现**："物种身份"是隐藏变量；三头（回归 + 硬分类 + 软分类）与域内预训练是关键。
- **关键数字**：1st 17,396 物种三头 + PlantCLEF 预训练 + 结构化自注意力 + 分层 LR；9th DINOv2+CatBoost 0.51238；6th EVA 单模 0.483–0.486、栈后 0.526；官方因 sample_submission 套利更换测试集并重置 LB。
- **可迁移配方**：① 找身份/群体结构做辅助任务；② 域内预训练；③ 分层学习率；④ 提交格式（列顺序）保护。
- **失效条件**：身份不可得或与目标弱相关。
- **证据**：510393 / 510188 / 510143 / 486503 / 487985。

## 四、CV：检测、分割与检索

### rsna-2024-lumbar-spine — 级联流水线与误差吸收
- **场景**：腰椎 MRI 多层面/多病变三分类，1874 队。
- **机制/发现**：级联（定位 instance_number → 分类）与把定位误差分布吸收进训练（±2 位移、xy ±10px、几何增强）是主增量。
- **关键数字**：instance_number 分类 ±0=71.08%、±1=27.04%、±2=1.43%；提升阶梯 2.5D 0.37 → attention MIL 0.35 → +bi-LSTM+aux+ensemble 0.33。
- **可迁移配方**：① 先定位后分类；② 把上游误差建模进下游训练；③ 多层面序列模型 + 辅助任务。
- **失效条件**：定位可完美时级联收益下降。
- **证据**：1st 帖与数据表。

### vesuvius-challenge-surface-detection — 表示 + 拓扑后处理
- **场景**：古卷 CT 表面检测，1391 队；指标惩罚体素与拓扑误差。
- **机制/发现**：SDF 表示、全卷推理、拓扑后处理三件事；公私榜脱钩。
- **关键数字**：1st 4 模型集成私榜 0.620–0.627；后处理链 0.596→0.614（去小连通）→0.622（补小洞）→0.625（高度图补大洞）→0.627（binary closing）；5th SDF + H1 隧道填充 13 轮 = 本地拓扑 +0.08。
- **可迁移配方**：① 指标含拓扑项就做拓扑后处理；② 表示选择（SDF vs 二值）；③ 全卷推理与阈值。
- **失效条件**：拓扑指标权重低时不值得投入。
- **证据**：1st/5th 帖。

### hubmap-hacking-the-human-vasculature — 模型之外的分数
- **场景**：肾活检 WSI 血管检测分割，1021 队。
- **机制/发现**：多阶段（检测→分割→分类）与后处理贡献过半；ViT-Adapter-L 单模最强。
- **关键数字**：3rd 多阶段验证 +2–3%、LB +4–6%；ViT-Adapter-L 公 0.600/私 0.589；erode + 单次 dilate +0.005。
- **可迁移配方**：① 先做多阶段系统；② 后处理在 CV/LB 上双验证；③ 单模架构选择（ViT-Adapter）。
- **失效条件**：端到端模型已足够强。
- **证据**：3rd 帖。

### image-matching-challenge-2024 — 分场景处理与几何先验

### feedback-prize-effectiveness — 伪标签 + 两级集成 + 校准

### learning-equality-curriculum-recommendations — 召回 + 阈值后处理
- **场景**：课程主题↔内容检索（F2 micro），1057 队；多语言、一对多、允许无匹配。
- **机制/发现**：主题树上下文注入提升召回；阈值/后处理把排序变集合；负样本设计与语言切换。

- **失效条件**：指标是纯排序（无阈值）时后处理不同。
- **证据**：learning-equality 深读 1st/2nd/3rd。

### foursquare-location-matching — 泄漏审计也是改进方案

- **场景**：玩家评分回归（RMSE），301 队；同一玩家历史整体落在 train 或 test。
- **机制/发现**：GroupKFold 更诚实但分数更低；分组与 LB 相关性需要实测，不能只凭教条。
- **关键数字**：KFold→GroupKFold 后"substantially worse"；StratifiedGroupKFold 改善有限；公开 starter 约 17.24339 RMSE；讨论区仅 12 帖。
- **可迁移配方**：① 先查实体块切分；② 分组/随机 CV 各记一版；③ 用多次提交的 CV-LB 相关决定信谁；④ 玩家/实体级特征严格"截至当前"。
- **失效条件**：实体不重复或跨折分布一致。
- **证据**：372554 / 362744 / 362735。

### gan-getting-started — 学习型赛的机会成本
- **场景**：Monet 风格生成（Getting Started），无奖励/无截止/无私有榜。
- **机制/发现**：价值在学习管线与资源图谱，不在排名；GAN 稳定训练 checklist + 提交 zip/PostProcessorKernel 是新手的两个坎。
