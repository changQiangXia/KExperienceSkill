# 指标结构套利与合法后处理

> 先读指标的数学结构，再决定模型与后处理。这里记录跨 264 场验证过的结构与对应动作；每条动作都必须先过 OOF 对照。

## 1. 指标分类 → 分数由谁决定

| 指标族 | 代表 | 分数由谁决定 | 可用的合法后处理 | 证据/案例 |
| --- | --- | --- | --- | --- |
| 均值型回归 | RMSE | 大误差样本（尾部） | 目标变换、稳健损失、winsorize | 通用 |
| 中位数型 | MedAE | **误差中位数那一个样本** | 对两端样本降权、预测向档位/分位整形 | AE≤0.06 或 ≥0.7 权重 0.01 → CV +0.03；9 档 ±0.25 覆盖 89.5%，猜对 ~56% 即 0.25；200+ 提交卡在 0.25 |
| 排序型 | AUC/NDCG/MAP/top-K | 相对次序 | 秩平均、校准不变融合、追加预测、top-K 截断 | Nov2022 单参数 logit 平移 −1.17 把 CV 0.6476→0.5281；S3E8 分组合法性裁剪再 +1.1 |
| 阈值型 | F1/Accuracy | 阈值附近样本 | 阈值搜索（OOF）、先验校正、两阶段分类 | 阈值/先验类后处理常值 1e-3–1e-2 |
| 容差型 | MAP@{K}/误差容差 | 落在容差内的比例 | target 整形、两极化流水线、档位化 | 计数/检测赛按容差设计输出 |
| 概率型 | LogLoss | 校准 + 区分度 | 温度缩放、isotonic（小心过拟合） | 小数据上单参数平移常优于 isotonic |
| 方差解释型 | R² | 大方差样本/异常值 | 极端值裁剪、分层建模、遵守"只计 >0"规则 | PlantTraits：极端标签与 R² 只计正值 |
| 对局型 | ELO/积分 | 长期胜率与对手分布 | 提交组合、对手池分析、终局构造 | Maze：主动逼迫有利 tiebreak；1st 对镜像仅约 53/47 |

## 2. 中位数/分位型：先做"权重 + 形态"

1. 计算 OOF 绝对误差分布，找出会落在中位数的样本区间；
2. 对远易/远难样本降权（例如 0.01），只让"边缘样本"主导梯度；
3. 把预测向训练分布的分位/整数档位整形（如 9 个硬度档）；
4. 用 OOF MedAE 选择阈值与档位，不要用 public LB 搜。

**边界**：测试分布必须与训练同构；档位/阈值是经验参数，换场需重扫。

## 3. 排序型：秩与校准分开

- 排序指标优先用**秩平均/校准不变融合**；概率平均会把校准误差带进融合。
- 低分追加预测（追加一批本来就该在后面的候选）在 top-K 指标下可能不伤分——先看指标实现再决定。
- 当分数扎堆（0.25 聚集、26.38–26.41），LB 微差没有信息量，用 OOF 与分布整形决策。

## 4. 单参数校准 vs 灵活校准

- 已知偏差方向时，**先试单参数平移**（logit 平移/乘子）；它不容易过拟合。
- isotonic/分段校准适合样本多且有明确单调失配；小数据上会过拟合阶梯。
- 任何校准都在 OOF 上拟合，且与不校准的同折对照比较。

## 5. 裁剪与合法性约束

- 目标有物理/业务上下界时，clip 是稳定增益；但先验证模型是否已在压缩极值（改了反而掉 LB 的案例存在）。
- 分组合法性裁剪：按关键分组（如 carat 窗 × 类别组合）用训练组的分位上/下界约束预测，比"清洗训练数据"更有效。
- 预测值形态（正数、整数、概率和=1）与评测实现对齐；不要交超出评测接受范围的值。

## 6. 后处理工作流（每场照做）

```text
1. 读官方 metric 实现，写单元测试（边界/空值/并列/平均口径）
2. 在 OOF 上枚举 3–5 个候选后处理：
   a. 无处理（基线） b. clip c. 校准 d. 档位/分位整形 e. 融合/秩变换
3. 选 OOF 最优且逻辑可解释的 1–2 个
4. 公榜只做 sanity check（是否大幅偏离 OOF 预期）
5. 记录：动作 / ΔOOF / ΔLB / 风险（是否依赖 public 分布）
```

## 7. 危险信号

- 后处理阈值是在 public LB 上搜出来的 → 私榜高风险；
- 指标实现有 bug 或与文档不一致（曾有 AUC 部分 bug、MAP@20 与代码不一致）→ 先核对官方实现；
- 只用"指标名字"猜行为（把 MedAE 当 MAE 优化）→ 方向性错误；
- 在窄分带上反复微调 → 用提交次数买噪声。
