# 实验协议（Experiment Protocol）：把"涨了"变成可证明的结论

> 深度补充：上一轮解决"为什么"（mechanisms）与"何时失效"（boundaries）；本协议解决"如何证明"。
> 目标：让每个改进结论都经得起复算、种子扰动、子群与多重比较检验。

## 1. 假设必须先写成可检验形式

```text
H0：改动 D 对主指标 M 无提升（Δ ≤ 0）
H1：改动 D 对主指标 M 有提升（Δ > 0）
主指标：唯一（例如 OOF MedAE）
最小可检测效应 MDE：你预先声明"多大提升才值得保留"（例：Δ ≥ 0.002）
决策规则：Δ̂ ≥ MDE 且置信区间下界 > 0 → 保留；否则回退
```

没有 MDE 的实验会被噪声牵着走。MDE 参考：0.001–0.01（Kaggle 前排差距常见量级）、相对提升 0.1–1%。

## 2. 方差来源分解

| 来源 | 表现 | 控制方法 |
| --- | --- | --- |
| 折间方差 | 5 折分数波动 | 固定折文件；报告均值 ± 标准差；重复 CV |
| 种子方差 | 换种子分数漂移 | 3–5 个种子；同种子配对比较 |
| 数据采样方差 | 小数据/小测试集 | 重复 CV / bootstrap；别用 LB |
| 指标估计方差 | 小样本指标噪声 | bootstrap CI；子群分析 |
| 平台/环境方差 | 版本/硬件差异 | 固定环境与版本；记录 run 元数据 |

**配对原则**：A/B 必须用**同一折、同一种子**跑，差异才是改动带来的；独立跑两遍的差异混入种子方差。

## 3. 需要多少重复才能检测 Δ

配对差异的近似样本量：

```text
n ≈ 2 (z_{1-α/2} + z_{1-β})² σ_d² / Δ²
α=0.05, β=0.2 → (1.96+0.84)² ≈ 7.85
n ≈ 7.85 σ_d² / Δ²      （σ_d = 配对差异的标准差）
```

经验表（σ_d 为单次重复的标准差）：

| σ_d / Δ | 需要重复数 n（近似） |
| --- | --- |
| 1 | 8 |
| 2 | 32 |
| 3 | 71 |
| 5 | 197 |

**实操**：先用 2–3 个种子估 σ_d；若 σ_d/Δ > 2，优先降低噪声（更多折/更多数据/更稳模型），而不是继续加种子。

## 4. 三阶段实验流程

1. **筛选（coarse）**：1 个种子 × 固定折，快速淘汰 Δ<0 的假设；只用主指标。
2. **确认（confirm）**：3–5 个种子 × 重复 CV，配对比较 + bootstrap CI；达到 MDE 才保留。
3. **稳健性（robust）**：子群（头部/尾部/实体/时间）、分布扰动、后处理敏感性；检查是否只在公榜/单折有效。

## 5. 决策规则（预注册）

- 主指标唯一；辅助指标只用于解释，不用于改判；
- 每个实验写下 kill 标准（如"ΔOOF < 0.001 或 CI 下界 ≤ 0 → 回退"）；
- 连续两轮无 OOF 增益 → 回到诊断，不继续调参；
- 任何"以 LB 为准"的决策必须先在提交台账里证明 CV-LB 相关性；
- 多重比较：并行假设 ≤3–5 个；超过则用独立 holdout 确认或降低显著性阈值。

## 6. 台账与产物（每次实验必须留）

```text
experiment_id / date / hypothesis / change
fold_file 路径 + 种子
cv_metric / cv_before / cv_after / delta / std
lb_before / lb_after（若有）
cost_min / decision（keep/revert/iterate） / kill 标准
OOF 预测文件路径（用于后续融合与审计）
```

工具：

- 折文件与台账骨架：`scripts/experiment_harness.py`
- OOF 指标 + bootstrap CI + 配对比较：`scripts/oof_report.py`
- 台账模板：`assets/experiment_ledger_template.csv`
- 单实验卡模板：`assets/experiment_card_template.md`

## 7. 常见统计错误

| 错误 | 后果 | 修正 |
| --- | --- | --- |
| 只看均值不看方差 | 把噪声当提升 | 报告均值 ± std / CI |
| A/B 用不同折/种子 | 无法归因 | 配对设计 |
| 先看结果再定 MDE | 事后合理化 | 实验前写 MDE 与 kill |
| 用 LB 做确认 | 私榜风险 | ≥5 次提交验证相关性后再用 |
| 在验证集上做特征选择/调参 | 乐观偏差 | 嵌套 CV / OOF |
| 多次试验只报最好 | 选择偏差 | 记录全部实验与失败 |
| 低信号目标堆实验 | 噪声上做多重比较 | 先做信号检验，设预算 |
| 子群不检查 | 只在头部/长尾有效被平均掩盖 | 分层报告 |

## 8. 一次实验的检查清单

- [ ] 假设写成 H0/H1 + 主指标 + MDE
- [ ] 固定折文件；A/B 同折同种子
- [ ] 至少 2–3 个种子估方差；σ_d/Δ 可控
- [ ] kill 标准写在实验前
- [ ] 结果写台账 + OOF 文件
- [ ] 决策记录（keep/revert/iterate）与原因
- [ ] 若涉及提交：先过 submission_guard，再记录 CV-LB 对照
