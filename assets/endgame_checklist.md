# 收官清单（截止前 48h → 提交）

## 冻结前（T-48h ~ T-24h）
- [ ] 停止引入新方法/新数据；只做复现、选择与格式
- [ ] 端到端重跑最终训练/推理链路，确认可复现
- [ ] 冻结模型版本、后处理参数、随机种子
- [ ] 选出 2–3 个候选提交（CV 最强 / 保守 / 多样）
- [ ] 写清每个候选的风险（public 依赖 / 分布假设 / 格式风险）

## 提交体检（T-24h）
- [ ] `python scripts/submission_guard.py --submission sub.csv --sample sample_submission.csv`
- [ ] 列顺序、行数、ID 集合、空值全部通过
- [ ] 代码赛：zip/图片/kernel 结构按官方要求演练
- [ ] Agent 赛：schema 本地校验通过、预算/超时保护生效
- [ ] 数据集/notebook 公开可见性用陌生账号检查

## 提交（T-24h ~ T-2h）
- [ ] 先提交保守候选，再提交 CV 最强候选
- [ ] 确认状态 Submitted（不是 Draft/Error），截图留证
- [ ] 记录提交时间、版本、分数；保留 1 次提交余量
- [ ] 不因 public LB 微差临时改选择（除非 CV-LB 相关性已证明）

## 冻结（T-2h ~ T-0）
- [ ] 最终选择 = OOF 依据 + 风险对冲结果
- [ ] 写下未选提交与原因（赛后复盘用）
- [ ] 确认没有任何凭证/私有数据进入提交物
- [ ] 确认比赛规则无遗漏（外部数据/共享/团队）
